# EU-Guidelines (kurz)

Quelle: Practical guidelines DG JUST, April 2026 (PDF hier im Ordner) bzw. [Commission](https://commission.europa.eu/publications/practical-guidelines-and-high-resolution-vector-files-eu-notice-and-label-product-guarantees_en).

- Notice online: Farbe, lesbar, Link wie QR (Your Europe).
- Prominent z. B. Footer/Checkout: kurzer Hinweis, volles Label per Klick/Hover.
- Notice auch in der Bestellmail (Theme/Vorlage muss das einbauen — Modul setzt nur GARAN-Variable `solutioo_eu_garan_note`).
- GARAN nur bei echter Haltbarkeitsgarantie (> 2 Jahre, ganze Ware, kostenlos); Nested → volles Label; nur XX/Brand/Model ändern.
- Checkout: kurzer Hinweis reicht; volles Label per Klick/Link (Warenkorb-Plugin ok; Onepage-Platzierung ggf. Theme).
